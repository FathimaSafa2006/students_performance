# students_performance

# Student Performance Analysis 📚

## Introduction
This project analyzes student performance using Python to understand how study hours, attendance, sleep, motivation, and other educational factors relate to exam scores.

The project uses Pandas, NumPy, and Matplotlib to explore student data, calculate statistics, identify patterns, and visualize academic performance.

## Objectives
- Analyze student exam scores.
- Calculate average, highest, and lowest exam scores.
- Study the relationship between attendance and exam scores.
- Analyze study hours and academic performance.
- Explore the relationship between sleep hours and exam scores.
- Compare exam scores across gender and motivation levels.
- Examine the relationship between teacher quality, internet access, and exam performance.
- Visualize student performance using graphs.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Dataset
The dataset includes student-related factors such as:
- Hours Studied
- Attendance
- Sleep Hours
- Gender
- Motivation Level
- Teacher Quality
- Internet Access
- Exam Score

## Project Workflow
1. Import Python libraries.
2. Load the student performance dataset.
3. Explore dataset shape, columns, and data types.
4. Check for missing values.
5. Calculate descriptive statistics using NumPy.
6. Analyze relationships between student factors and exam scores.
7. Group and compare average exam scores.
8. Create visualizations using Matplotlib.
9. Summarize findings and conclusions.

## Analysis and Visualizations

## Key Findings
The project explores how attendance, study hours, sleep, motivation, teacher quality, and internet access relate to student exam performance.

The notebook findings highlight the importance of examining these factors to better understand student academic outcomes.
